# Graphic-Protofolio-By-Amr

Graphic design portfolio by Amr Essam — logos, cinematic car posters, and client work.

Live: https://devvoltx.github.io/Graphic-Protofolio-By-Amr/
Main portfolio: https://devvoltx.github.io/Amr/

## Structure
- `index.html` — page markup (must be at the repo root)
- `style.css` — all styles
- `script.js` — slide navigation (dots + arrow keys)
- `images/` — avatar, logos, car posters, client work
- `.nojekyll` — tells GitHub Pages to serve files as-is

## Deploy
Upload everything to the repo root, then Settings > Pages > Deploy from a branch > `main` / `(root)`.
